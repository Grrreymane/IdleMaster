## 0. 结论先说

- 节奏目标：前 5 分钟每 10~30 秒一次小提升；第一次进化 ≈ 7 分钟；第一个守关大妖 ≈ 19 分钟，打过瞬间战力 ×4.3；每区比前一区慢；积极玩家（每天在线 6 h + 两晚离线）≈ 1.4 天通关大荒。
- 「有收益又不爆炸」的骨架完全照 STI：**玩家每级只涨 ×1.15，敌人每级涨 ×1.45**，差距用四种**离散、有限、看得见**的来源补——装备品质（×1.6/档）、进化（×2.5/阶）、本体等级（×1.03/级）、山海图鉴（×1.005/点，按区封顶，打大妖释放）。
- 真正卡进度的是**区域材料**（每杀固定掉 1 个）；灵石只涨 ×1.05，永远不卡人。
- 峰值：大荒大妖血量 ≈ 2.5e15（2500 兆），玩家攻击 ≈ 1.6e14，全程 double，显示用 万/亿/兆/京/垓。
- 涅槃做加法（+5%/精魄，封顶 60 点），不碰「打大妖→释放上限」这个主爽点。

### 它为什么「有收益又不爆炸」

1. **两条慢曲线 + 几级台阶**。玩家每级 ×1.15、敌人每级 ×1.5，光升级永远追不上。能追上的只有：品质（×1.6/档，掉率 1/5000~1/450000）、每 10 级的技能里程碑（+15%~50%）、Mastery。都是离散、有限、玩家能数得清的东西。
2. **Mastery 按区封顶**。`1.005^M` 同时乘攻击和生命，但没杀本区 Boss 之前被 `masteryCap` 压住，刷收藏碾压不了当前区；杀 Boss 的一瞬间释放，一次 ×2~×30。这是最大的爽点，也是本设计的核心手法。
3. **货币压平**。贝壳成本只按 1.05 涨，属性按 1.15 涨；按财富比例给的奖励都有 `clamp`。真正的瓶颈是每杀只掉 1 个的区域材料。
4. **离线是固定速率、只刷已熟练（≥100 杀）的怪**，只补材料和图鉴，不会让数值失控。
5. **经验分段放大 D**（200 → 2000），后期自然变慢。
6. **克制差 12.5 倍**（2.5 / 0.2），「选对武器」比「多刷」更有效，给卡关留出路。
7. 全程峰值 ~1e14，不需要大数库。

## 2. 山海异兽录 数值模型

### 2.0 符号

| 符号 | 含义 | 范围 |
|---|---|---|
| `k` | 地图分区 1..8（南山 / 西山 / 北山 / 东山 / 中山 / 海外 / 海内 / 大荒） | 1..8 |
| `L` | 怪物等级 = `10(k−1) + {1,4,7,10}`（易 / 中 / 难 / 大妖） | 1..80 |
| `Lv` | 本体等级（用精元升） | 1..80 |
| `Ls` | 某部位强化等级 | 0..80 |
| `r` | 装备品质档 凡0 / 灵1 / 玄2 / 仙3 / 神4 / 圣5 | 0..5 |
| `s` | 进化阶 | 0..6 |
| `M` | 山海图鉴点数 | 0..~3360 |
| `cap_k` | 第 k 区图鉴上限 | 见 2.7 |

### 2.1 属性（分层相乘，层内相加）

```
EQ(Ls, r)   = 7 × 1.15^Ls × 1.6^r                       // 一件装备的基础值
攻击 ATK    = (5  + Σ攻击部位 EQ)  × 1.03^Lv × 2.5^s × 1.005^M_eff × (1 + 涅槃攻%)
生命 HP     = (50 + 5·Σ防御部位 EQ) × 1.03^Lv × 2.5^s × 1.005^M_eff × (1 + 涅槃血%)
```

- 攻击部位 4 个：角饰、爪套、尾饰、灵珠（灵珠同时决定攻击五行）。
- 防御部位 3 个：鳞甲、项圈（铃）、护体符纹。
- `M_eff = min(M, cap_k)`，本区大妖杀过后 `M_eff = M`（见 2.7）。
- 显示用「战力」= `ATK^0.6 × HP^0.4 × 2`，只用于 UI 和换装比较。
- 没有防御属性（和 STI 一样），生存靠 HP 和回复。

### 2.2 战斗规则

| 项 | 值 |
|---|---|
| 异兽出手 | 2.0 s 一击 |
| 怪物出手 | 2.5 s 一击 |
| 刷怪间隔 | 0.5 s |
| 单次伤害 | `ATK × 克制 × 暴击 × rand(0.9, 1.1)` |
| 暴击 | 5%，×2 |
| 五行克制 | 克 ×2.0，被克 ×0.5（金克木、木克土、土克水、水克火、火克金）。只看攻方 vs 守方 |
| 怪物伤害 | `eATK × rand(1.00, 1.05)` |
| 回复 | 普通战斗每秒 2% 最大生命；大妖战每秒 1% |
| 阵亡 | 10 s 后满血复活，退回本区「易」；大妖战失败 90 s 后可再挑战 |
| 大妖 | 可重复挑战（冷却 90 s），为了刷妖丹和图鉴 10 杀 |

### 2.3 本体等级与精元

```
升到 Lv+1 需要精元  XP(Lv)   = 60 × 1.5^(Lv−1)
每只怪给精元        xp(L, k) = 60 × 1.5^(L−1) / D_k
D_k = 10 × 1.6^(k−1) → [10, 16, 25.6, 41, 65.5, 105, 168, 268]        // 调
大妖首杀精元 = XP(10k) × 0.5
```

- 打同级怪时一级正好要 `D_k` 只；一区 10 级共需约 `D_k × 10 × 1.5^±2` 只，低于该区材料总需求（见 3.1），所以等级**不会**成为卡点，但能稳定每 30~90 s 跳一次。
- 本体等级只给 `1.03^Lv`（80 级 ×10.6），是「一直有收益」的那根细线；没上限卡区（卡关时还能慢慢升）。

### 2.4 进化（主线爽点）

每阶 `×2.5` 攻击和生命，换立绘。条件 = 本体等级 + 大妖精血（该大妖首杀必掉 1 枚）+ 灵石。

| 阶 | 形态 | 条件 | 预计时点 |
|---|---|---|---|
| 0 | 狌狌（南山经） | 开局 | 0 |
| 1 | 类（南山经·亶爰之山） | Lv 8 | ≈ 7 min |
| 2 | 狡（西山经） | Lv 9 + 狍鸮精血 | 打过大妖 1（≈ 19 min） |
| 3 | **选线**：灵狐 青丘狐 / 凶兽 猾褢 / 龙蛇 肥遗 / 瑞兽 鹿蜀 | Lv 19 + 帝江精血 | 打过大妖 2 |
| 4 | 三尾狐 / 狰 / 螣蛇 / 驺虞 | Lv 38 + 梼杌精血 | 打过大妖 4 |
| 5 | 六尾天狐 / 蛊雕 / 蛟 / 夫诸 | Lv 58 + 相柳精血 | 打过大妖 6 |
| 6 | 九尾狐 / 穷奇 / 应龙 或 烛龙（龙蛇线二选一）/ 白泽 | Lv 68 + 窫窳精血 | 打过大妖 7 |

- 线路五行：灵狐 火、凶兽 金、龙蛇 水、瑞兽 木，0~2 阶 土。本体五行只决定**被克**；攻击五行由灵珠决定，所以选线不会把人锁死。
- 等级门槛故意比「到达该区时的预期等级」低 1~2 级，避免「打过大妖却差一级不能进化」。
- 涅槃后可走另一条线，形态收进图鉴（每个形态 +30 图鉴点）。
- 进化灵石费 = `50 × gold(10k)`（见 2.9）。

### 2.5 装备

**部位**：角饰、项圈、鳞甲、爪套、尾饰、灵珠、护体符纹，共 7 个。
**品质**：凡 / 灵 / 玄 / 仙 / 神 / 圣（r = 0..5，颜色 灰 / 绿 / 蓝 / 紫 / 橙 / 金红光效）。

**强化等级在部位上，不在物品上**（和 STI 的区别，理由：换了新品质不用从 0 重练，也不需要「军械库」）。物品只提供品质 `r` 和外观，图鉴按「装备名 × 品质」点亮。

```
强化 Ls → Ls+1：
  材料  MAT(Ls, r)  = ceil( 2.5 × 1.035^Ls × (1 + 0.4 r) )          // 调 2.5 / 1.035
  灵石  GOLD(Ls, r) = 4 × gold(Ls) × (1 + 0.5 r)                       // 永远不卡
  材料种类：Ls mod 10 ∈ {1,2,3} 用该区「易」材料，{4,5,6} 用「中」，{7,8,9} 用「难」，
            Ls = 10k 升 10k+1 为「突破」：妖丹_k ×1（大妖 k 首杀 3 枚、复杀 1 枚、本区小怪 1/300）
  强化上限  = 10 × (已击败大妖数 + 1)                                  // 没杀大妖 k，所有部位停在 10k
```

材料数示例：Ls 0→1 要 3 个，9→10 要 4 个，39→40（仙）要 22 个，79→80（圣）要 105 个。
