## 2. 击杀奖励（⚠ 修正："1 个区域材料"不准确）

每次击杀（`rpg.js:187-385`）：
- **该怪专属材料 ×1**：`dropItem()` 里 `itemdrop = 1;`（`rpg.js:1642`）。每只怪掉的材料不同（E1→I1、E3→I51、E2→I37…），不是"区域通用材料"。
- **经验**：`Math.round(exp * playerEXPGain)`（`rpg.js:243`）。
- **区域掉落表**滚一次：`rollTable(A?Loot,1)`（`rpg.js:211`），例如 `A1Loot = { I10:{P:200}…, 遗物:{P:generalRelicDrop=60000}, M1:{P:100000} }`（`gameObjects.js:8455`, `8452`）→ 宝箱 1/200。
- **元素小水晶** 1/500（对应怪的元素）：`smallCrystalDropChance = 500`（`rpg.js:232-237`）——武器突破要用。
- 稀有装备掉落见 §8。
- 1/50 概率刷出礼物怪 E15（窗口有焦点时）：`rng(1,50) === 1`（`rpg.js:94`）。
- **没有按击杀给贝壳**（贝壳主要来自点击、任务、卖东西）。

## 3. 装备数值

```
gameObjects.js:167-185
rarityPower: Poor 0 / Common 1 / Uncommon 2 / Rare 3 / Epic 4 / Mythic 5
weaponTier = (tier 未定义) ? 1 : tier+1
weaponPower = rarityPower + weaponTier - 2
return 25 * 1.15^level * 1.6^weaponPower * mod
```

- ✅ 公式正确。换算：**无 tier 的 Common = 0 档**，品质每升一级或 tier 每 +1 都 ×1.6。Poor 是 ×0.625。
- 同一个公式**也用于防具的 HP**（如 `items.I2.stats = 'feetAdditiveMaxHp = rUpgDmg("I2", 1)'`，`gameObjects.js:4057`）。mod 绝大多数是 1（武器 21 件 =1，个别 0.5/0.85/2/2.5/3）。
- 每 10 级 ×1.15^10 ≈ **×4.05**；60 级 ≈ ×4384。
- **等级上限**：`let itemCap = 61`（`rpg.js:4368`），即 0~61 级。（⚠ 修正：不是 0~60。）
- **被动/主动技能解锁**：⚠ 不是"每 10 级一个"。`rUpgSkill(id, text, type, cap)` 的 cap 每件装备自定，统计到的解锁等级有 0/10/15/20/30/35/40/45/50/55/60/70/80（最多的是 0、50、30、60、40）。例：木剑 10 级 +20% 力量系加成（`gameObjects.js:3396`），月光大剑 35/45/55（`gameObjects.js:3449`）。`items.X.cap` 只用于"放大镜提前揭示技能"（`rpg.js:4371`），并不限制升级。

## 6. 伤害公式

普通攻击（`rpg.js:461-473` → `rpg.js:1054` 起 → `rpg.js:969-1050`）：

```
base   = 武器各元素伤害之和（通常只有一个非零）   // 空手 = 固定 10，不吃任何加成
dmg    = base × (1 + 该元素Bonus) × playerStrength          // type "str"
dmg   ×= 2.5（克制） 或 0.2（被克）                           // rpg.js:964 typestrength=2.5; :965 typeResist=0.2 ✅
dmg    = dmg × 1.005^Mastery × enemyDefenseMultiplier × crit
final  = rng(dmg×0.9, dmg×1.1)                                 // ±10% ✅
```

- **暴击**：固定 `rng(1,20)===1` → **5%，×2**（`rpg.js:975-978`）。`playerCritChance` 虽在 statsUpdate 里算了，但伤害函数没用它。
- **元素克制环**（攻→被克）：自然→力量→神秘(occult)→神圣(deific)→元素→自然，每个都 ×2.5；反方向 ×0.2（`rpg.js:1054-1166`）。"vortex" 天气下整个反转。
- **受到伤害**：`damage − damage × 元素抗性`（`rpg.js:1216` 起），没有平减防御；敌人伤害 `rng(atk, atk×1.05)`（`rpg.js:644`）。
- **加成合成**（`statsUpdate`，`gameObjects.js:604-819`）：
  - 元素加成 `XBonus = (Σ加法项) × Π(1+乘法项)`，最终 ×(1+XBonus)（如 `gameObjects.js:735-737`）。
  - 力量 `playerStrength = 1 + 加法和 × 乘法积`（`:687`）；法强同理（`:698`）。
  - 最大 HP `((25 + 防具HP和) × Π乘法) × 1.005^Mastery`（`:681`）——**基础 HP 只有 25，HP 几乎全靠防具**。
  - 经验 `playerEXPGain = 1 + 加法和 × 乘法积`（`:672`）。
  - 预期伤害 `expectedPlayerDamage = 武器伤害 × Π(1+各元素Bonus) × 力量 × 法强 × 1.005^M`（`:814`）。
- **角色等级本身不加属性**（`updateClass` 里 baseStrength/baseMaxHp 被注释掉，`rpg.js:910-913`）。等级只用来开区域、给天赋点。

## 7. Mastery（精通）

```
gameObjects.js:644
playerMastery = 任务完成数×10 + 收藏品×5 + 军械库(图鉴装备)×10 + 怪物金牌×10(解锁图鉴后) + 日志×5 + 植物完成度×6
```

- ⚠ 补充：没有"击杀数"直接来源；金牌要单怪击杀 ≥10,000（`logs.js:717`），铂金 ≥100,000（`logs.js:724`）。

- **首杀首领释放上限**：`rpg.js:360-366` 弹出 "Mastery cap released!" ✅。
- 乘区：伤害 `rpg.js:982`、HP `gameObjects.js:681`，都是 **1.005^M** ✅。

## 8. 经验曲线与任务

- `returnExp(L) = floor(1000 × 1.5^(L−1))`（`gameObjects.js:963-967`）；升级后 `nextExp = 1000×1.5^level`（`rpg.js:820`），即 L→L+1 需要 returnExp(L) ✅。
- 怪物经验 = returnExp(怪等级)/D，D：A1 **200**、A2 **300**、A3/A4/A8 **1800**、A9 **2000**；地牢小怪 0 ✅。→ 打同等级怪约 D 只升一级。
- 等级上限：无职业 30（`gameObjects.js:11688`），转职后 60；无职业满 30 后每 6 级 1 天赋点（`rpg.js:831-832`）。
- **任务奖励**（`rpg.js:3812-3820`）：经验 = **当前 nextExp × 40%**；贝壳 = `clamp(总贝壳×25%, 500, 250000)`（任务可自定 money 覆盖）。任务目标多是"杀 N 只 / 攒 N 个材料"：如 A1Q4 Stinglet 150 只，A2Q3 240 只，A3Q4 600 只，A3Q2 攒 2500 个 I37，A8Q1 1000 个（`gameObjects.js:8622-9336`）。

## 10. 离线

`main.js:1181-1240`, `1429-1660`：
- 门槛：离线 **>60 秒**；且当前怪 **killCount > 99**、不在地牢，才结算战斗收益。
- 击杀数 = 离线分钟 × `playerPenguinPower/15`，基础 PenguinPower=100 → **≈6.67 杀/分钟**（≈9 秒一杀，比在线 2 秒一刀慢）。
- 收益：主材料 ×击杀数、经验 = 怪 exp × 击杀数（**不乘经验加成**），稀有掉落按 `1/(N/击杀数)` 一次结算，收藏品按一半击杀数。
- **没有时长上限**（代码里没 cap）。建筑进度单独封顶 8640（`main.js:1213`），地牢次数最多 +2、上限 3。

## 11. 生存 / 死亡 / 节奏相关

- **回血**：非首领/地牢战斗中每秒回 **5% 最大 HP**（`rpg.js:604-605`）→ 普通怪几乎不会打死你，除非单下伤害接近满血。首领战不回血。
- **死亡**：首领打死你 → 退回 easy、清掉首领（`rpg.js:497-508`）；地牢死亡直接出地牢。死后**不会自动回血**，要点乌龟，每点 +8% 最大 HP（`rpg.js:587-589`），满血复活。
- 首领可随时手动挑战，失败无惩罚（只是回到 easy），首杀给保底首通奖励（`rpg.js:278`）。
- 点击：每次 `(10 + 加法) × 乘法` 贝壳，冷却 100 ms（`gameObjects.js:785-787`，`main.js:197-252`）。

### "一直在进步但不爆炸"的骨架

1. **区域内**：材料按等级段锁到具体怪物，装备每级 ×1.15，每 10 级要一次首领材料 + 元素水晶 → 装备等级被区域进度卡住。
2. **跨区域**：敌人 HP 每区 ×40~×100；玩家这边靠装备 10 级 ×4、品质/tier 每档 ×1.6、元素克制 ×2.5、精通上限提升（×2.7~×30）补齐。
3. **精通上限**是防爆阀：外部系统（任务、收藏、图鉴、花园）攒的精通在当前区首领死前用不出来。
4. **首领是墙**：HP 是同区 easy 的 200~400 倍、不回血，必须"装备 + 精通 + 克制"都到位。
5. 经验 D 值随区域放大（200→2000），等级只作门槛，不直接加战力。
